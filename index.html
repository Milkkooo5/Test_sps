1. Информационная и вычислительная система, ПО

  • Вычислительная система — один или несколько компьютеров + при необходимости сетевая среда и периферия + ПО, организованные для обработки информации.
  • Информационная система (в широком смысле) — помимо железа, ПО и данных включает персонал, пользователей и всё обеспечение их работы (методическое, материально-техническое).
  • Если человек — постоянный компонент системы наряду с техникой, это человеко-машинная (автоматизированная) ИС.
  • Субъекты ИС (активные): программные процессы и человек. Объекты (пассивные): обрабатываемая информация и оборудование.

Типы ПО

  • Системное ПО — обеспечивает функционирование самой вычислительной системы и её взаимодействие с внешним миром. Его фундамент — операционная система.
  • Инструментальное ПО — сюда относятся снифферы (Wireshark).
  • Защита доступа к данным в БД — прикладное ПО категории систем безопасности (засчитывали и «СУБД»).
  • Драйвер — программа для низкоуровневого управления оборудованием и предоставления высокоуровневого доступа к нему другим программам.
  • Алгоритм (программа) — набор команд CPU, выполнение которых решает задачу. Интерпретируемые программы (скрипты) предназначены не для CPU, а для исполнительной среды.

Архитектуры распределённых ИС

  • Локальная (файловая) → файл-серверная → клиент-серверная (централизованный доступ к общему ресурсу) → двухзвенная → трёхзвенная — наибольшая масштабируемость.
  • В трёхзвенной ИС веб-сервер выполняет роль сервера приложения обработки данных.
  • World Wide Web — клиент-серверная распределённая система. Компонент, реализующий пользовательский интерфейс Web, — HTTP-клиент (браузер).
  • Сетевая программная служба — два+ процесса на разных узлах, решающие общую задачу через сеть.
  • Роли клиента (осуществляет доступ к ресурсу) и сервера (предоставляет ресурс в общий доступ) определены для программных процессов на узлах.
  • Веб-сайт — совокупность веб-страниц с общим расположением, тематикой и оформлением.

2. Операционные системы

Задачи и функции ОС

Управление оборудованиемУправление программной средой
создание аппаратных абстракций и предоставление их процессам; разделение ресурсов во времени и в пространстведиспетчеризация процессов; синхронизация процессов по отношению к общим ресурсам
  • Функции ОС: загрузка кода и данных в ОЗУ, распределение памяти (вкл. виртуальную), защита от НСД. Не функция: «идентификация установленного ПО и данных».
  • Способы разделения ресурса между процессами: диспетчеризация (во времени) и мультиплексирование в пространстве. Абстрагирование и виртуализация — не способы разделения.
  • Аппаратные абстракции: накопитель → файловая система; ОЗУ → виртуальная память; системная плата для ядра → HAL.

Диспетчеризация и процессы

  • Механизмы диспетчеризации: вытесняющая многозадачность, квантование времени CPU, приоритизация. Синхронизация — не механизм диспетчеризации.
  • Диспетчер задач управляет доступом к процессору.
  • Состояния процесса: выполняется, готов к выполнению, блокирован. Состояния «синхронизирован» нет.

Синхронизация процессов

  • Критическая область — фрагмент кода процесса с обращением к общему ресурсу (ответ «критическая секция» не засчитывали!).
  • С активным ожиданием: блокирующие переменные, запрещение прерываний, алгоритм Петерсона. Минус — трата CPU на пустой цикл.
  • С блокировкой: семафор Дейкстры, мьютекс. Проблемы: взаимная блокировка и инверсия приоритетов.
  • Транзакция — многошаговый перевод БД из одного целостного состояния в другое, выполняется целиком или не выполняется вообще.

3. Память, диски, файловые системы, RAID

  • Основная память — ОЗУ (не кэш, не регистры, не диск). Основа внутренней памяти — оперативная память (RAM).
  • Проблемы физической памяти без абстракций: дефицит физической памяти и вмешательство программ друг в друга при абсолютной адресации.
  • Виртуальная память — абстракция, где у каждого процесса своё адресное пространство.
  • Сектор — минимальная адресуемая единица на диске. Кластер — единица выделения места файлам в FAT/NTFS. Цилиндр — все дорожки одной зоны всех дисков на шпинделе.
  • Файловая система — способ организации, хранения и идентификации файлов на накопителе (низкоуровневого доступа не даёт, защита конфиденциальности не обязательна).
  • ACL есть в NTFS (рекомендуется для Windows NT) и ext4; нет в FAT32 и HPFS.
  • Разметка в стандартном BIOS (MBR): до 4 разделов — 4 основных или 3 основных + 1 дополнительный.

4. Сети и адресация

Модель TCP/IP (DoD)

УровеньПротоколыЕдиница данных / адрес
ПриложенийRDP, DNS, HTTP, DHCP, Telnetсообщение → сокет (адрес подсети + узла + порт)
ТранспортныйTCP, UDPсегмент — в его заголовке номер порта
МежсетевойIP, ICMPпакет → IP-адрес
Доступа к сетиARP, Ethernetкадр → физический (MAC) адрес
  • Сокет — полный адрес программного процесса в межсетевой среде.
  • Функции сетевого интерфейса: физическая адресация, контроль целостности кадров, кодирование сигнала. Не относится: контроль целостности IP-пакетов.
  • Сигнал — физический процесс передачи материи с информацией. Кодирование — создание сигнала из битов кадра.
  • MTU — макс. размер поля данных кадра; им же на практике задан размер IPv4-пакета.
  • Трейлер кадра с контрольной суммой (FCS) нельзя увидеть в Wireshark. Wireshark захватывает трафик из буфера сетевой карты; показывать нужные кадры — фильтр отображения.

Адреса

ТипЗона действия
MAC-48 (физический)подсеть определённой архитектуры
Частные IPv4своя подсеть; могут повторяться благодаря NAT
Публичные IPv4вся интегрированная сеть
DNS-имена (до 255 байт)вся сеть; это система доменных имён (ответ «доменное имя» не засчитывали)
  • Широковещательные: Ethernet — ff-ff-ff-ff-ff-ff; 192.168.0.0/24 → 192.168.0.255; 10.0.0.0/8 → 10.255.255.255; ограниченный — 255.255.255.255. Localhost — 127.0.0.1.
  • Маска /27: 32−27 = 5 бит на узлы → 2⁵−2 = 30 узлов.
  • Класс A реально используется 126 сетей (0 и 127 зарезервированы).
  • IPv6 = 128 бит. В ::ffff:x.x.x.x под «::» скрыто 128−16−32 = 80 двоичных нулей. Адрес :: — это 32 шестнадцатеричных нуля.
  • ARP — MAC по IP, запрос идёт широковещательной рассылкой. Кадр для узла другой подсети адресуется на MAC шлюза (в тесте засчитали ответ «адресата»).
  • NAT — сопряжение частной и публичной IPv4-сетей.

Оборудование и маршрутизация

  • Маршрутизатор (роутер) — физический интерфейс между подсетями.
  • Сегментируют канал на домены коллизий: коммутатор, мост. Не сегментируют: хаб, повторитель.
  • RIP — небольшие сети (до 15 хопов), Беллман–Форд. OSPF — крупные сети, алгоритм Дейкстры.
  • Взаимодействие гетерогенных сетей: трансляция (полное переформатирование пакета) и туннелирование/инкапсуляция (пакет едет в поле данных транзитной сети) — сейчас наиболее востребовано.

Беспроводные и доменные сети

  • Причины беспроводных сетей: рельеф, где нельзя проложить кабель; много мобильных пользователей.
  • Особенности: нет локализации сигнала, пассивное прослушивание обнаружить нельзя.
  • Многоранговые (доменные) сети: централизованное управление, высокая масштабируемость.
  • Состояние СКС в реальном времени отслеживают системы автоматизированного управления инфраструктурой СКС.

6. Информационная безопасность

Термины

  • Конфиденциальность — ограниченный круг лиц с легальным доступом. Целостность — отсутствие семантического искажения / внутренняя непротиворечивость. Доступность — легальный доступ беспрепятственен.
  • Угроза — потенциальное событие, способное нанести ущерб. Уязвимость — свойство ИС, которое может привести к реализации угрозы. Риск — количественная вероятность реализации угрозы.
  • Уязвимость нулевого дня — защитный механизм ещё не разработан.
  • НСД — получение доступа с нарушением установленных правил.
  • Идентификация — распознавание по идентификатору. Аутентификация — проверка подлинности. Учётная запись — регистрационные данные для аутентификации и авторизации.

  • Фишинг — на легковерности пользователя.
  • Сетевая разведка: сканирование портов, DNS-запросы.
  • Комбинированные атаки: атака эксплойтом, атака ботнетами.

7. Облака, блокчейн, Docker, Git

  • IaaS — ИТ-ресурсы нужной мощности без покупки и обслуживания железа. PaaS — для команд разработчиков. SaaS — готовое ПО.
  • Блокчейн: децентрализованный доступ, криптографическое шифрование реестра, открытость реестра транзакций.

8. Пользовательские интерфейсы

  • Оболочка — программа, реализующая пользовательский интерфейс ОС.
  • Оболочка командной строки (shell) = интерпретатор команд и пакетных файлов + командная строка.
  • WIMP (Windows, Icons, Menus, Pointer) — концепция с меню и позиционирующим устройством.
  • Визуальные интерфейсы по способу взаимодействия: оконный и текстовый (по статистике теста).
  • Виды интерфейсов: пользовательский — CLI; сетевой — NIC; между подсетями — роутер.
